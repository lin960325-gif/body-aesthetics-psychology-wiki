# 來源資料庫

本頁彙整目前各篇文章使用的主要來源。來源的用途不同：博物館資料主要支持物件與歷史脈絡；學術論文支持特定研究結果；理論原著支持概念定義。引用時請回到原文核對，不要只根據搜尋摘要轉述。
